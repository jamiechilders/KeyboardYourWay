# Keyboard Your Way

Stage 1 Android foundation for a privacy-first customizable keyboard.

Current scope: standalone input method service, basic English QWERTY typing, space, backspace, setup screen, and Android keyboard enable/picker entry points. No typed content or analytics are collected.

Long-term decisions are documented in the project conversation. Advanced visual editing, profiles, custom rows, hidden/additional keys, and premium controls will be added in later stages after the foundation is tested.
